# 🎄 메리 리틀 크리스마스

벽난로 앞에 옹기종기 모여서 이야기하는 크리스마스 놀이방이에요.

## 실행하는 법

1. [Node.js](https://nodejs.org) 설치 (LTS 버전, 한 번만 하면 돼요)
2. `실행하기.bat` 더블클릭 (또는 이 폴더에서 `node start.js`)
3. 브라우저에서 **http://localhost:3000** 접속

외부 패키지가 없어서 `npm install` 없이 바로 돌아가요.

## 친구 초대 (다른 와이파이 · LTE · 노트북 · 폰)

`실행하기.bat`으로 켜면 **어디서든 들어올 수 있는 주소**(`https://○○○.trycloudflare.com`)가 자동으로 만들어져요.

- 서버 창에 주소와 QR코드가 떠요
- 사이트 위쪽 **🔗 친구 초대** 버튼을 누르면 QR이랑 복사 버튼이 나와요
- 친구는 QR을 찍거나 링크를 눌러서 → 닉네임·비밀번호로 가입하면 바로 들어와요

알아둘 것
- 처음 실행할 때 Cloudflare의 무료 터널 도구 `cloudflared.exe`(약 60MB)를 이 폴더에 한 번 내려받아요
- **내 컴퓨터에서 서버 창이 켜져 있는 동안만** 열려 있어요. 컴퓨터가 잠자기 모드로 들어가면 끊겨요
- 서버를 껐다 켜면 주소가 바뀌어요 → 새 QR을 다시 공유해 주세요
- 링크를 가진 사람은 누구나 들어올 수 있으니, 아는 사람한테만 보내 주세요
- 주소가 안 만들어지면 `cloudflared.exe`를 지우고 다시 실행해 보세요. 그래도 안 되면 같은 와이파이 주소(`http://192.168.x.x:3000`)로는 계속 들어올 수 있어요
- 처음 실행할 때 Windows 방화벽 창이 뜨면 "허용"을 눌러주세요 (같은 와이파이 접속용)

## 고정 주소로 올리기 (컴퓨터를 꺼도 열려 있게)

무료 서비스 3개를 써요. 셋 다 GitHub 계정으로 가입할 수 있어요.

| 서비스 | 하는 일 |
|---|---|
| GitHub | 코드 보관 |
| Render | 서버 실행 → `https://이름.onrender.com` 주소 |
| Upstash | 가입한 계정 정보 저장 (Render 무료 서버는 재시작하면 파일이 지워져요) |

1. **GitHub**: 새 저장소(repository) 만들기 → "uploading an existing file" → `public` 폴더, `server.js`, `package.json`, `.gitignore`, `README.md` 를 끌어다 놓고 Commit
   (`cloudflared.exe`, `data`, `config.yml`, `실행하기.bat`, `start.js` 는 올리지 않아요)
2. **Upstash** (console.upstash.com): Redis 데이터베이스 만들기 → 화면의 **REST** 칸에서 `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 두 값을 복사
3. **Render** (render.com): New → Web Service → 1번 저장소 선택
   - Build Command: `npm install` / Start Command: `node server.js` / Instance Type: **Free**
   - Environment Variables 에 2번의 두 값을 그대로 추가
   - Deploy → 몇 분 뒤 `https://○○○.onrender.com` 주소가 생겨요

무료 서버의 특징
- 15분 동안 아무도 없으면 잠들어요. 다음 사람이 들어올 때 깨어나는 데 1분쯤 걸려요 (그동안 Render 로딩 화면이 보여요)
- 접속 중일 때는 연결이 잠깐 끊겨도 자동으로 다시 붙어요
- 가입한 계정은 Upstash에 저장돼서 사라지지 않아요. 채팅 기록과 방 안 위치는 서버가 잠들면 초기화돼요
- 지금 설정: Render · Upstash 모두 싱가포르, 무료 플랜

## 🎂 다 같이 케이크 만들기

방 가운데 티테이블(또는 아래 🎂 메뉴)을 누르면 열려요. 모두가 **케이크 하나**를 같이 만들어요.

0. **모이기**: 처음 누른 사람이 👑 방장 → 다른 사람은 "참여하기" → 방장이 "시작하기" (중간에 참여도 가능)
1. **재료 넣기**: 밀가루 · 설탕 · 소금 · 계란 · 우유 · 버터 (필수) + 색 재료 9가지: 코코아 · 말차 · 딸기 · 레드벨벳 · 단호박 · 블루베리 · 바나나 · 흑임자 · 버터플라이피 (섞을수록 시트 색이 섞여요)
   - 소금이나 설탕을 너무 많이 넣으면 먹을 때 🥵 / 🤤
2. **거품기로 섞기**: 그릇 위를 빙글빙글 돌려서 섞어요 (같이 돌리면 더 빨라요)
3. **굽기** (4초)
4. **크림 색 정하기**: 과일을 넣으면 크림 색이 바뀌어요
5. **크림 바르기**: 스패출러로 케이크 위를 직접 문질러 칠해요 → 다 칠하면 예쁜 크림 모양으로 완성
6. **토핑**: 생크림 꽃 · 딸기 · 체리 · 블루베리 · 마카롱 · 민트 · 초코하트 · 스프링클 · 호랑가시 · 별 · 초 + 테두리 생크림
7. **촛불 불기** → **8조각 나눠 먹기**

- 다음 단계는 👑 방장만 넘길 수 있어요 (방장이 나가면 남은 사람에게 넘어가요)
- 케이크 창이 떠 있어도 채팅을 보고 칠 수 있어요 (폰은 창 아래에 최근 채팅 4줄)
- 누가 케이크를 열거나 시작·완성하면 방 위쪽에 📢 공지가 떠요

## ☕ 주방 · 🎒 인벤토리

방 왼쪽 주방 카운터를 누르면 열려요.

- **핫초코**: 우유(꾹 눌러 붓기 · 덜기)랑 코코아 가루(＋/－, 최대 6스푼)를 마음대로 → 비율에 따라 밍밍·연한·딱 좋은·진한 맛 → 빙글빙글 젓기 → 토핑
- **마시멜로 굽기 (타이밍 게임)**: 불에 올리면 점점 빨라지며 구워져요. 빨간 선이 반짝이는 칸에 왔을 때 "지금 빼기!" → ✨완벽한 황금 마시멜로 (칸 위치·속도는 매번 달라요)
- 만든 건 오른쪽 아래 **인벤토리 4칸**에 들어가요 (계정에 저장)
- 칸을 누르고 **✋ 손에 들기** → 캐릭터가 손에 들고 있어요 (다른 사람에게도 보여요) → 아래 **먹기/마시기** 버튼(또는 Q 키)으로 세 입 냠냠 · 호로록
- 🎆 폭죽: 아래 버튼이나 F 키

케이크는 서버 메모리에 있어서, 서버가 잠들면 처음부터 다시 만들어요.

## 🎄 다 같이 트리 꾸미기

- **오너먼트**: 방울 7색 · 지팡이 사탕 · 종 · 리본 · 진저브레드 · 눈꽃 · 별 · 양말 · 전구 5색 → 고르고 트리를 톡
- **줄 장식**: 반짝이 · 구슬 · 전구 · 리본 줄 → 트리 위를 쭉 그어서 걸기 (한 사람당 4줄)
- **꼭대기**: 별 · 리본 · 눈꽃 · 달 (모두 같이 바꿔요)
- **선물**: 트리 아래 바닥에 선물 상자 놓기
- **소원 카드**: 산타 할아버지께 바라는 선물을 적어서 걸기 (누르면 누가 뭘 적었는지 보여요)
- 내 장식은 끌어서 옮기거나 눌러서 떼요 (한 사람당 24개). 다른 사람 장식을 누르면 누가 달았는지 보여요
- ✨ 불 켜기: 밤 배경에서 전구가 반짝반짝
- 방 안의 트리에도 꾸민 장식이 그대로 보여요

## 🎁 선물 랜덤 교환

방 안 "선물 교환" 상자(또는 아래 🎁 메뉴)를 누르면 열려요.

1. **그림 그리기**: 9가지 색 · 굵기 3단계 · 지우개 · 되돌리기
2. **포장하기**: 포장지 5가지 + 리본 4가지, 이름 숨기기(익명)도 가능
3. **교환 상자에 넣기** → 상자 안에 다른 사람이 넣은 선물이 있으면 그중 하나가 랜덤으로 나와요 (내 선물은 나에게 안 와요)
   - 상자가 비어 있으면 기다렸다가, 다른 친구가 선물을 넣는 순간 바로 받아요 (접속 안 해도 선물함에 들어와요)
   - 한 번에 하나씩 교환해요
4. **받은 선물함 (5칸)**: 넘치면 열어 본 오래된 선물부터 빠져요. 흔들흔들하는 새 선물을 누르면 뚜껑이 뿅 열리고 그림이 나와요. 💾 저장 가능
- 선물이 오면 방 위쪽에 알림이 뜨고, 아래 🎁 메뉴에 빨간 숫자가 붙어요
- 그림은 계정 저장소와 따로 저장돼요 (Upstash `gimg:*` 키)

## ❄️ 눈마당 (바깥)

거실 왼쪽 빨간 문(또는 아래 ⛄ 눈마당 메뉴)으로 나가요. 다시 들어올 땐 집 문이나 🔥 벽난로 메뉴를 눌러요. 같은 방에 있는 사람끼리만 보여요 (채팅은 같이 써요).

- 가끔 산타 썰매와 루돌프 그림자가 하늘을 지나가요. 밖에서는 달 앞을, 거실에서는 창문을 지나가요
- 선물 교환: 📷 사진을 넣고 그 위에 그림을 그려서 보낼 수 있어요

## 🛠️ 개발자 모드

닉네임 **개발자** 는 서버 환경 변수 `ADMIN_PW` 에 넣은 비밀번호로만 가입·로그인할 수 있어요 (비밀번호는 코드에 넣지 않아요). 로그인하면 위쪽에 🛠️ 버튼이 생기고, 트리 · 눈사람 · 눈성 · 선물 상자 · 케이크 · 미니게임 · 채팅 기록을 초기화할 수 있어요. 비밀번호 맞히기를 막으려고 1분에 5번까지만 시도할 수 있어요.

## 파일 구조

```
크리스마스/
├─ server.js        서버 (웹 + 실시간 채팅, 계정 저장, 공개 주소 만들기)
├─ 실행하기.bat      더블클릭 실행 (내 컴퓨터용)
├─ start.js         실행 도우미 (cloudflared 준비 → 서버 → 브라우저)
├─ public/
│  ├─ index.html    화면 구성
│  ├─ style.css     디자인
│  ├─ avatar.js     캐릭터 그림(SVG)
│  ├─ sound.js      효과음 · 캐롤 BGM 재생
│  ├─ credits.html  배경 음악 출처
│  └─ app.js        화면 동작
└─ data/users.json  계정 정보 (실행하면 자동 생성, 비밀번호는 암호화해서 저장)
```
